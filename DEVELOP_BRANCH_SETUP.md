# Upload to the develop branch

1. Confirm GitHub Desktop shows branch `develop`.
2. Copy all files and folders from this package into your local ShelterPro repository, replacing existing files when asked.
3. In GitHub Desktop, review the changed files.
4. Summary: `Build Shelter Pro 2.0 static modular foundation`
5. Click **Commit to develop**.
6. Click **Push origin**.
7. Test locally with VS Code Live Server before merging to `main`.

Your current live GitHub Pages site remains safe because Pages continues to publish from `main`.
