# Free GitHub Pages setup

1. Create a new public GitHub repository named `shelter-pro`.
2. Upload every file from this folder to the repository root.
3. Open repository **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then save.
7. Wait for GitHub to show the published address.
8. Open that address in iPhone Safari and use **Share → Add to Home Screen**.

GitHub Pages hosting has no monthly subscription for this static project.
